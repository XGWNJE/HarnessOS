# 全局协作规则

## 执行与验证

- 严格按我的要求确定工作范围：不额外做，也不遗漏要求做的事。
- 完成后默认做快速验证，例如运行项目已有的 IC、代码检查；修复本次改动引入的问题。
- 如果验证需要视觉检查或较长的操作链路，先停下来，让我选择由你执行验证，或由我按验收步骤检查。
- 交付时只列出本轮任务需要我验收的内容和操作步骤。

## 沟通

- 默认使用简洁中文，优先说大白话；只有确有必要时才使用术语。
- 积极使用选项式提问，让我能直接选择；说明各选项的代价和推荐项。

## 文件与安全

- 不将密钥、token、私钥或生产配置写入公开位置或版本历史；发现泄露时提示更换并作废旧凭据。
- 我要求记住的长期偏好写入合适的持久规则；项目特有约束留在项目中，不扩散为全局规则。
- README 面向人，AGENTS.md 面向 Agent。README 头部按 README 模板书写；两份文档的正文只保留框架、简短总结和索引，详细内容放在独立文档中并提供链接。
- 修改既有文件前遵循其项目规则；不要为了套用文档规范而新建无必要的文档。
