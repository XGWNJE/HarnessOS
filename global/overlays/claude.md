# Claude Code 专属规则（overlay）

> 本文件是 global/AGENTS.md 的 Claude Code 专属补充，发布时拼接在核心规则之后，仅写入 ~/.claude/CLAUDE.md。
> 写法：目标模式——只描述想要的目标与验收标准，不规定具体做法。

## 协作目标（Claude 专属补充）

- **并行拆解用得其所**。验收：适合并行的任务（大项目、杂乱历史构建、多模块/日志/测试失败/迁移路径需同时排查）实际用了子智能体；每个子智能体动手前职责、文件范围、读写权限、等待条件、汇总格式已划清；同一文件/模块不被多个子智能体同时修改；最终结果由主线程整合并验证。
- **关键取舍可决策**。验收：需要 owner 选择时，选项为 2-4 个，各标代价，有明确推荐项。
- **代码资产英文、用户可见文案中文**。验收：变量、函数、类、文件、目录、注释、日志、错误、测试、提交信息、配置键为英文；用户可见文案、README、CLAUDE.md、设计/部署/操作说明为中文；既有中文标识符不被无关重构。
- **文档读者清晰、无大段重复**。验收：README 面向人（用途、快速开始、日常入口、常用命令、安全提醒）；CLAUDE.md 面向 Agent（边界、文件职责、验证步骤、危险操作、敏感信息、提交/发布规则）；专题细节在专题文档，其他文档只留摘要和链接；重复内容只保留在最适合读者的文档里。
- **文档与实际同步**。验收：构建/运行/测试/部署命令、目录结构、入口、依赖、配置方式变化后，README 与项目级 CLAUDE.md 与实际一致，快速开始可照做。
- **提交节奏由 owner 掌控**。验收：只有 owner 明确要求才执行 commit；进度适合保存时主动提醒并说明建议提交范围；提交前查过 git status、不混无关文件；owner 已有改动不被覆盖、回滚或丢弃；commit message 中文、简洁说明目的。
- **sing-box DNS 不被污染**。验收：TUN 模式下 `protocol: dns → hijack-dns` 排在所有路由规则第一位（紧跟 `sniff`），其前无任何进程级规则——否则私有 IP（如路由器）的 DNS 查询绕过劫持直连路由器，拿到 ISP 污染结果。
- **中文文件字节级干净**。验收：仓库文本 UTF-8 无 BOM；PowerShell 读写中文文本显式指定 UTF-8；见到 `鏄`、`涓`、`â€"`、`` 等疑似乱码先停下用 UTF-8 字节核对，不把乱码当真实内容编辑；改动中文 Markdown/JSON/代码/配置后无新增乱码、替换字符或异常 BOM。
