# Claude Code 专属规则

> Claude Code overlay | 目标模式

## 协作目标

- **并行用得其所**：适合并行的任务用子智能体；各子智能体职责/文件范围/读写边界事先划清，不同时改同一文件；主线程整合验证。
- **关键取舍给选项**：需 owner 选择时给 2-4 个选项，各标代价，有推荐。
- **代码英文、文案中文**：标识符/注释/日志/提交信息英文；用户可见文案/README/设计说明中文。
- **文档精炼不重复**：README 面向人，CLAUDE.md 面向 Agent；专题细节在专题文档，其余文档只留链接。
- **提交由 owner 掌控**：owner 要求才 commit；提交前查 git status 不混无关文件；message 中文简洁。
- **中文字节级干净**：UTF-8 无 BOM；PowerShell 写中文显式指定 UTF-8；遇乱码先字节核对不盲改。
