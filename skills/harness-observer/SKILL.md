# Harness Observer（静默观察者）

目标：把有规则价值的观察安静、准确地送进 HarnessOS 原料区；观察不能改变或阻断当前任务。

## 验收标准

- 静默观察不在对话中提及、不请求确认；显式投递除外。
- 观察只追加到 `$HARNESSOS_ROOT/notes/inbox/`；不改 `global/`、`skills/`，不运行 git、sync 或 publish。
- 记录不含密钥、token、凭据、私密 URL、完整提示词或工具输出。
- 同主题近 30 天内只保留一条；再次出现时递增重复计数并补一句新证据。

## 记录范围

| 信号 | 类型 |
|---|---|
| owner 明确表达的偏好、习惯或验收标准 | 声明式规则 |
| owner 重复纠正但未明说 | 待确认 |
| 踩坑及实际结果 | 归纳式原料 |
| Agent 的假设、目标、路径或范围错误 | 归纳式原料 |

## 记录格式

```markdown
## <一句话主题>
> 日期：YYYY-MM-DD
> 场景：语言/工具/任务类型
> 类型：待确认 | 声明式规则 | 归纳式原料
> 来源项目：<项目名或路径>
> 重复计数：<n>

观察事实。脱敏：不写密钥、token、私密 URL。
```

## 机制

1. 按 `HARNESSOS_ROOT`、当前项目规则中的路径、`D:\ObjectCode\HarnessOS`、`~/ObjectCode/HarnessOS` 的顺序定位可写原料区。
2. 显式要求“投递/记录到 HarnessOS”时同样只写原料区；投递不等于固化。
3. 原料区不可写时静默跳过；仅在本次会话结束时提示有未落盘的观察数量。
