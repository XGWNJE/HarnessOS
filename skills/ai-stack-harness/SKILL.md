# AI 编程技术栈选型参考

`global/AGENTS.md`「AI 协作与工程判断基线」是判断与验收的真相源；本文件只保留下列可核验的参考事实与机制细节。

## 选型服务于反馈闭环（详细验收清单）

判断一项技术是否适合 AI 编程，看「生成之后能否快速检查、验证、修正」，而非「AI 能不能写出它的代码」。验收维度：

- **反馈机器可判定**：错误信号来自编译器报错、类型检查、测试通过/失败，而非人眼判断。
- **反馈足够快**：反馈速度纳入选型；高频迭代下反馈慢的选项被显式排除或说明代价。
- **上下文集中**：结构/逻辑/样式能在相对集中的上下文修改，评估过 AI 在文件/范式间的跳转成本。
- **约束清晰统一**：对 AI 而言，所选方案的约束与规则清晰统一，优先于「无限自由」的方案。
- **生态语料充足**：公开代码量与 AI 理解深度被核实过；小众技术只在有明确理由时入选。
- **失败代价匹配约束强度**：越接近底层（系统调用、数据、权限）错误代价越高，强类型/编译检查类技术价值越明显。
- **社区真实信号**：参照 GitHub issue、迁移公告、一线开发者的弃坑记录等一手信号，不以 benchmark/榜单为主。
- **轻量替代代价问清**：任何以轻量、小巧为卖点的替代方案，其牺牲项（一致性？生态？可控性？）被明确列出并权衡。

## 推荐分层栈（owner 实战结论）

来源：owner-declared（owner 实战选型判断，2026-07 确认）

| 层 | 技术 | 为什么 |
|---|---|---|
| 底层/性能敏感 | **Rust** | 严格类型系统 + 编译器检查提前暴露问题，给 AI 稳定明确的反馈，特别适合「生成—编译—修正」循环快速收敛 |
| 应用逻辑 | **TypeScript** | 静态类型将错误前置；npm 生态的网络效应（连 Deno 都回头兼容 Node/npm）；关注编译性能进展（如原生编译器），补上反馈速度一环 |
| 界面 | **React + Tailwind CSS** | React 组件化把界面拆成边界清晰的结构/状态/交互，公开代码多、AI 理解充分；Tailwind 把样式收敛为可组合、可预测的工具类，AI 不用在组件、样式文件、命名体系间跳转 |
| 运行容器 | **Electron** | Chromium（Agent 观察/操作 Web 的窗口）+ Node.js（连接本地系统/工具的执行层），是天然的 Agent 行动载体；过去的缺点（体积大、资源占用高）在 Agent 时代转化为优势——Agent 恰好需要完整、可编程、跨平台的行动环境 |

组合效果：Agent 可在相对集中的上下文中同时改结构、逻辑与样式，再通过类型检查和视觉反馈迅速验证。

## 技术选型验收红线（详细事实）

- **不推荐 Tauri 替代 Electron**：系统 webview 不确定——不同系统、不同版本表现不一致，webview 有 bug 时无法自行修复只能等系统升级；跨平台一致性差（正是 Electron 用打包 Chromium 换来的东西）；窗口/配置 API 有限、新开授权弹窗与文件下载需自行处理；实战信号：OpenCode 桌面端从 Tauri 迁回 Electron（「WebKit is asssss. Moving to Electron very soon.」）。包体积减小的收益抵不上稳定性与 Node.js 生态的损失。
- **不推荐自编译 Chromium 跑 Chrome 插件**：源码+依赖数十 GB，官方要求预留 100GB 磁盘，首次全量构建几十分钟到数小时；三平台需分别维护工具链、补丁、签名、自动更新、回归测试；拿回的是底层能力，并不会自动得到完整 Chrome（Web Store、账号、策略、插件生命周期、权限治理都没有）；最终维护的是一条浏览器厂商级别的内核与发行链路。
- **成熟生态当护城河**：npm、Chrome 插件体系等成熟生态计入选型权衡；任何替代方案先回答「生态网络效应损失怎么补」。
- **不采信半实现 API**：兼容性评估对齐「可观察语义」（参数校验、错误作用域、事件投递、生命周期），不以方法名清单为准；方法存在、调用不报错但语义只做一半的 API 识别为高风险（会在很远下游以难定位的方式失败）。

## 长链路任务证据链收敛回路（机制）

模型单次生成无法闭环复杂系统任务；这是一套无可替代的收敛回路（非步骤建议），具体每一环用什么工具、走几遍由模型按情境自决：

```
官方文档 → 上游源码 → 本地实现 → 自动化测试 → 真实环境运行 → 视觉回放 → 发现偏差 → 回到文档和源码
```

三要素：模型能力 + 工具链 + 多模态（视觉验证），长链路任务尤其依赖三者协作。
