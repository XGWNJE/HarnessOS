# 项目文档边界（原则已在全局规则）

「每份文档只负责自己的事实」的约定已上移进 `global/AGENTS.md`「文档边界」一节，此处不重复维护；本文件只保留操作细节。

## 责任表（操作参考）

| 文档 | 负责的事实 | 不负责 |
|---|---|---|
| README.md | 项目是什么、如何开始、文档导航 | 操作细节、完整规则、历史记录 |
| AGENTS.md | 当前项目的操作约束、入口、验证与维护事实 | 项目宣传、通用全局规则副本 |
| CHANGELOG.md | 已完成变更的历史 | 计划、当前操作说明 |
| 专题文档 | 一个明确专题的完整事实 | 其他专题或重复摘要 |
| 文档地图 | 每份文档的名称和责任 | 文档正文的复制 |

项目没有某类文档时，不为满足模板而新建；先确认是否真的需要一个新的事实主人。

## 纠正流程

1. 读取目标项目的 README、AGENTS.md、CHANGELOG、文档地图和与问题有关的专题文档。
2. 为每段内容标出唯一主人：重复的保留在主人文档；错位的移入主人文档；过期链接、路径和摘要按真实文件修正。
3. 使用项目已有的文档检查命令，再按变更类型完成项目自己的验证。

## 边界

- 不创建或分发全局规则；全局规则已有自己的源和发布流水线。
- 不初始化项目、生成规则体系或替项目决定业务约束。
- 不管理截图、视觉样式、发版流程、MCP、CLI 或环境配置。
